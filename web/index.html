Twin plate vector displacement

Two images are the model.

A solid can be stored as a pair of images. Both plates sit on the same center. One faces up, the other faces down, and each pixel is the vector from that center out to the surface. The files can be 16-bit PNG or OpenEXR. A mesh of any size is a resample of those two files.

plate + plate − resampled mesh

1 · Formula

The solid is math: a sphere, a box, a torus, a cone, a capsule, a mushroom, a rippled ball. Nothing is loaded from a modeling tool.

2 · Outward rays

Both plates occupy the same center. The upper face fires up. The lower face fires down. Lean splays both rays away from the middle, so the stored vector picks up X and Z.

3 · Two files

Hit minus plate point is the vector. Red, green, and blue are X, Y, and Z. PNG stores them in 16-bit, with the middle code as zero. OpenEXR stores the same vector as a float, and zero means zero. Alpha is the mask.

4 · Any grid

Reconstruction decodes the files, adds the vectors back onto the plates, and stitches a wall around the silhouette. A coarser grid is a lighter mesh from the same files.

P(u,v) = O(u,v) + vector(R, G, B)

PNG packs that vector into 16-bit channels, biased so 32768 is zero. OpenEXR writes the same numbers as floats, and zero is no displacement. A brush is one OpenEXR: the upward plate only. Drop a second file when the solid has a downward plate too. Drag to orbit, scroll to zoom.
